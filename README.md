# لُب | Lub Studio

غرفة عمل عربية لصناعة المحتوى من الأخبار والبيانات: أفكار وقصص، مصادر، إنتاج، مراجعات، اعتماد، خطة نشر، مهام وفريق، ومؤشرات تشغيل داخلية.

## الحالة الحالية

نسخة أولى تعمل باستخدام React وTypeScript وVinext، مع Cloudflare D1 وDrizzle لحفظ البيانات. تدعم الواجهة العربية واتجاه RTL. يحتوي المستودع على المصدر وترحيلات قاعدة البيانات والاختبارات؛ لا يحتوي على بيانات الإنتاج أو الأسرار.

النشر إلى X وإحصاءات الجمهور غير مربوطين بعد. مواعيد النشر تخطيطية، وإثبات النشر اليدوي يستخدم رابط المنشور. أعضاء الفريق حاليًا للإسناد فقط، وليست لهم حسابات دخول وصلاحيات مستقلة. المواد المرئية تُربط بروابط، والرفع المباشر غير منفذ.

## التشغيل المحلي

المتطلبات: Git، وNode.js بالإصدار 22.13 أو أحدث، وpnpm بالإصدار المحدد في `package.json`.

```sh
git clone https://github.com/sabq4org/lub-studio.git
cd lub-studio
pnpm install --frozen-lockfile
pnpm run build
```

بعد أول بناء، هيّئ قاعدة البيانات المحلية **مرة واحدة**:

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_silky_wraith.sql
pnpm run dev
```

افتح العنوان الذي يطبعه الخادم، وعادةً `http://localhost:5173`. قاعدة البيانات المحلية منفصلة عن قاعدة النسخة المنشورة. لا تُعِد تطبيق الترحيل الأول على قاعدة مهيأة بالفعل.

## التحقق

```sh
pnpm run typecheck
pnpm test
pnpm run build
```

الاختبار يستخدم قاعدة D1 معزولة ويتحقق من الحفظ، وانتقالات العمل، ومتطلبات المراجعة، وإلغاء الاعتماد بعد تعديل المادة، وتعارض نسخ التحرير، وحفظ أعضاء الإسناد والمهام.

## التطوير في Codex

استنسخ المستودع وافتح مجلد `lub-studio` كمشروع. اقرأ `AGENTS.md` و`IMPLEMENTATION.md` قبل التعديل، واستخدم فرعًا مستقلًا لكل تغيير. العمل على هذا المستودع لا ينشر تعديلات تلقائيًا إلى النسخة الحالية.

## الملفات الأساسية

| المسار | المسؤولية |
| --- | --- |
| `app/studio.tsx` | واجهة غرفة العمل |
| `app/api/workspace/route.ts` | حفظ البيانات والتحقق وانتقالات القصص |
| `lib/model.ts` | النماذج وقواعد الاعتماد والفجوات |
| `lib/storage.ts` | التخزين والتهيئة |
| `db/schema.ts` و`drizzle/` | مخطط البيانات والترحيلات |
| `scripts/check-lub.mjs` | اختبار التكامل |

## الاستضافة والوصول

النسخة الأصلية منشورة على Sites. إعدادات البناء الحالية تشمل تكامل Sites وCloudflare D1. نقل الكود إلى GitHub لا ينقل قاعدة بيانات الإنتاج، ولا يغيّر الاستضافة أو صلاحيات الوصول. معرّف المشروع الموجود في `.openai/hosting.json` يحدد النسخة الأصلية، وليس مفتاح وصول.

الوصول الخاص للنسخة الحالية تفرضه منصة الاستضافة. قبل استضافة التطبيق خارجها، يجب تنفيذ مصادقة وتفويض خادميين؛ لا تعرض واجهات البيانات للعموم باعتبار أن الواجهة وحدها تحميها.

تفاصيل بيئة التشغيل الموروثة في `docs/RUNTIME.md`، وحدود النسخة وخطة الإكمال في `IMPLEMENTATION.md`.
